# Deploy Menaya BeYom to Vercel

The site is finished. To publish it to the free `*.vercel.app` address:

## Easiest
- **macOS:** double-click `deploy.command`
- **Windows:** double-click `deploy.bat`

## Or by hand (any OS)
In this folder, run:

```bash
npx vercel@latest deploy --prod
```

The first run logs you in once (opens a browser), then publishes.
You'll get a live URL like `https://menayabeyom.vercel.app`.

> Requires Node.js installed (https://nodejs.org). Nothing else to set up.
